# About Me

**Hello, I'm Erika. 👋**

I like creating things that are beautiful, functional, and accessible. My background is what you can call _multidisciplinary_: design, web dev, data analytics, and even some IT. Add in a splash of customer service experience, my own tech headaches, genuine curiosity, and a user-focused, iterative process is born.

Career lingo aside... I like to keep up with seasonal anime, play too much Genshin Impact, and enjoy spending time with my family's cats. I also enjoy observing the decentralized web (mostly Lemmy + Mbin) and learning about digital privacy.

Exploring the Fediverse inspired me to create this blog instead of posting on typical social media. This way I can chronicle my work, thoughts, and experiences on my own terms. (One day I'll try Forgejo instead of GitHub!)

## ✦ Topics

Possible topics include:
- **Creative pursuits**: design, videos, mock-ups.
- **Code exploration**: web dev and data projects, current topics in the industry. 
- **Hardware + IT experiences**: builds I've done or troubleshooting I did. 
- **Open source adventures**: the decentralized web, using Linux, local AI.
- Plus my thoughts on whatever I find interesting!

## ✦ AI Use

Yes, I use AI. Mostly as my editor, code troubleshooter, and brainstorm partner.
